# Hviezdičky

Učenie hrou pre Huga (3) a Oliverka (6). Jedna HTML stránka: otvor `index.html` v prehliadači.

Pri hostovaní cez HTTPS možno aplikáciu pridať na plochu; ikona a názov sa načítajú z manifestu.

- každý chlapec má vlastný profil, levely, hviezdičky a nálepky
- Oliverko má písmenkové levely, prepisovanie slov a dopĺňanie chýbajúcich písmen
- otázky číta hlas prehliadača (slovenský hlas, ak je dostupný)
- postup sa ukladá v prehliadači (localStorage)
- písma sa načítavajú z Google Fonts, bez internetu sa použije systémové písmo
